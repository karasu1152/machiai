## 1. デザイン方針

### 1.1 3秒ルール

ゲストが見る画面（キオスク・ステータス・サイネージ）は、**3秒で理解できること**を絶対条件とする。
説明文を足したくなったら、それは設計が間違っているサイン。

### 1.2 情報の階層

各画面で「最も大きい要素」は1つだけ。それ以外は明確に小さくする。

| 画面 | 最大の要素 | 2番目 |
|---|---|---|
| キオスク（トップ） | キュー選択ボタン | 言語切替 |
| キオスク（発券後） | 待ち番号 | QRコード |
| ゲストステータス | **あと N組** | 自分の番号 |
| サイネージ | 呼出中の番号 | 呼出先の窓口 |
| 待ち行列管理 | 「次を呼ぶ」ボタン | 待機列 |

### 1.3 配色

```
プライマリ    #0f766e （深いティール。ホテルの落ち着きに合う）
アクセント    #b45309 （琥珀。レストラン用キューの識別色）
警告          #d97706 （長時間待ちの黄）
危険          #dc2626 （呼び出し・エラーの赤）
背景          #fafaf9 （温かみのあるオフホワイト）
文字          #1c1917
```

キューごとの `color` はカードの左端のバーとサイネージの見出しに使う。背景全体は塗らない（可読性のため）。

### 1.4 タッチターゲット

| 用途 | 最小サイズ |
|---|---|
| キオスクの主要ボタン | 高さ **160px** 以上（手荷物を持った状態・高齢者を想定） |
| キオスクの補助ボタン | 88×88px |
| スタッフ画面のボタン | 56×56px |
| 破壊的操作（取消・削除） | 他のボタンから **24px以上離す** |

## 2. 発券キオスク `/k/:tenantSlug`

iPad横向き固定。フルスクリーン（ホーム画面に追加してスタンドアロン表示）。

### 2.1 ステップ構成

```
[ステップ1] キュー選択  →  [ステップ2] 詳細入力  →  [ステップ3] 発券完了
                              （設定次第でスキップ）
```

**最短3タップで完了する。** チェックイン（詳細入力なし）なら「チェックインを選ぶ → 発券する」の2タップ。

### 2.2 ステップ1: キュー選択

### 2.5 キオスク運用上の設定（iPad側）

| 設定 | 値 | 理由 |
|---|---|---|
| 設定 > 画面表示と明るさ > 自動ロック | **なし** | 画面が消えると発券できない |
| 設定 > アクセシビリティ > アクセスガイド | **オン** | 他アプリへの離脱を防ぐ（トリプルクリックで起動） |
| Safariで開いて「ホーム画面に追加」 | 実施する | アドレスバーが消えフルスクリーンになる |
| 電源 | 常時接続 | |

## 3. ゲストステータス `/t/:token`

スマホ縦向き。**状態によって画面が大きく変わる。**

### 3.1 待機中（`waiting`）

```
┌──────────────────────────┐
│ グランドメルキュール浜名湖    [JA▾] │
│ レストラン（朝食）          │
├──────────────────────────┤
│                          │
│      あなたの番号          │
│      ┏━━━━━━━━━┓          │
│      ┃  R-024  ┃          │
│      ┗━━━━━━━━━┛          │
│                          │
│  ────────────────────    │
│                          │
│        あと                │
│                          │
│      ┏━━━━━━━┓            │
│      ┃   3   ┃  組        │  ← 画面最大の要素（180px級）
│      ┗━━━━━━━┛            │
│                          │
│      目安 約12分           │
│                          │
│  ────────────────────    │
│                          │
│  ● リアルタイム更新中       │  ← 緑の点が明滅
│                          │
│  ┌──────────────────┐    │
│  │ 🔔 順番が近づいたら │    │  ← Push対応端末のみ
│  │   通知を受け取る    │    │
│  └──────────────────┘    │
│                          │
│  この画面を開いたまま       │
│  お待ちください。          │
│  館内モニターでも          │
│  お呼び出しいたします。     │
│                          │
└──────────────────────────┘
```

| 挙動 | 仕様 |
|---|---|
| リアルタイム更新 | `queue_states` を購読。変化時に `get_ticket_status` を呼び直す |
| 「あと N組」の変化 | 数字が変わるとき、スケールアニメーション（1.0→1.15→1.0、300ms）で気づかせる |
| 画面消灯の抑止 | `navigator.wakeLock.request('screen')` を呼ぶ。失敗しても無視 |
| 通知ボタン | `Notification.permission` が `default` のときだけ表示。iOSでスタンドアロンでない場合は「ホーム画面に追加すると通知を受け取れます」と案内に差し替える |
| 接続インジケータ | Realtime接続中は緑の点。切断中は灰色＋「再接続中…」 |
| 音声のアンロック | 初回タップ時に無音の `AudioContext` を再生して、後の着信音を鳴らせるようにする（iOSの自動再生制限の回避） |

### 3.2 呼出中（`called`）— 最重要画面

```
┌──────────────────────────┐
│                          │
│   ███████████████████    │  ← 画面全体が赤 (#dc2626)
│   █                 █    │     0.6秒周期で明滅
│   █   お呼び出し中   █    │
│   █                 █    │
│   █  ┏━━━━━━━━━┓    █    │
│   █  ┃  R-024  ┃    █    │
│   █  ┗━━━━━━━━━┛    █    │
│   █                 █    │
│   █  レストラン入口   █    │  ← counter_name
│   █  までお越しください █    │
│   █                 █    │
│   █   [ 確認しました ] █   │  ← タップで明滅・音を止める
│   ███████████████████    │
│                          │
└──────────────────────────┘
```

| 挙動 | 仕様 |
|---|---|
| 背景 | `#dc2626` ⇄ `#fef2f2` を0.6秒周期で交互に。**30秒で明滅を停止**（バッテリー配慮）し、赤の静止画面になる |
| 音 | `/sounds/guest-call.mp3` を3回再生。ユーザーが一度も画面をタップしていない場合は鳴らない（ブラウザ制約） |
| 振動 | `navigator.vibrate([400,200,400,200,400])`（Androidのみ動作） |
| 再呼出 | `called_count` が増えたら、明滅と音を再度トリガーする |
| 「確認しました」 | 明滅・音を停止するだけ。DBの状態は変更しない（ゲストが誤って完了にできないようにするため） |

### 3.3 その他の状態

| 状態 | 表示 |
|---|---|
| `serving` | 落ち着いた緑の画面。「ご案内中です。ごゆっくりどうぞ。」 |
| `done` | 「ありがとうございました。またのお越しをお待ちしております。」 |
| `no_show` | 黄色の画面。「お呼び出しいたしましたが、確認できませんでした。**お手数ですが受付までお声がけください。**」 |
| `canceled` | 灰色。「この整理券は無効になりました。」 |
| `NOT_FOUND` | 「この整理券は見つかりません。QRコードをもう一度読み取ってください。」 |
| `EXPIRED` | 「この整理券は期限切れです。」 |

## 4. サイネージ `/s/:tenantSlug`

iPad横向き、またはPCをHDMIでTVに接続。**3m離れて読めること**が絶対条件。

```
┌──────────────────────────────────────────────────────────────────┐
│  グランドメルキュール浜名湖                                    07:42       │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│                    ただいまお呼び出し中                            │
│                                                                  │
│         ┏━━━━━━━━━━━━━━━━━━━━┓      ┏━━━━━━━━━━━━━━━━━━━┓        │
│         ┃                    ┃      ┃                   ┃        │
│         ┃      R-024         ┃  →   ┃   レストラン入口    ┃        │
│         ┃                    ┃      ┃                   ┃        │
│         ┗━━━━━━━━━━━━━━━━━━━━┛      ┗━━━━━━━━━━━━━━━━━━━┛        │
│              ↑ 画面高さの40%を占める（240px以上）                   │
│                                                                  │
│   直前のお呼び出し   R-023      R-022      C-018                  │
│                                                                  │
├──────────────────────────────────────────────────────────────────┤
│  ▌フロント チェックイン    4組待ち    約15分                        │
│  ▌レストラン（朝食）      12組待ち    約30分                        │
└──────────────────────────────────────────────────────────────────┘
```

| 挙動 | 仕様 |
|---|---|
| 呼出検知 | `queue_states.called_seq` の増加で判定 |
| 点滅 | 番号カードが3回点滅（背景をキューの `color` ⇄ 白、0.5秒周期） |
| 複数キューの同時呼出 | 呼出をキューに積み、1件ずつ4秒間隔で表示する |
| 無呼出時 | 「ただいまお呼び出し中の番号はありません」＋下部の待ち状況のみ |
| 自動復旧 | 30秒ごとに `queue_states` の `updated_at` を確認。90秒以上更新がなければ `location.reload()` |

### 5.1 「次を呼ぶ」ボタン

| 仕様 | 内容 |

### 5.2 待機列の1行

```

   番号    人数   席希望    部屋番号   経過   警告  メニュー
```

| 列 | 表示 |
|---|---|
| 番号 | 24px・太字 |

### 5.3 呼出中エリア

呼出中のチケットを最大3件まで表示（複数窓口が同時に呼んでいる場合）。

| ボタン | 動作 |
|---|---|
| **ご案内** | `set_ticket_status('serving')`。到着した |
| **再呼出** | `call_ticket()`。サイネージが再点滅し、ゲストのスマホが再び光る |
| **不在** | `set_ticket_status('no_show')`。確認ダイアログを出す |
| （長押し） | 「完了」ショートカット。呼んですぐ終わる運用向け |

経過時間が3分を超えたら、そのカードを黄色にして「不在」を促す。

## 8. 多言語対応

### 8.1 対応言語

| コード | 言語 | 備考 |
|---|---|---|
| `ja` | 日本語 | 既定 |
| `en` | English | |
| `zh` | 简体中文 | |
| `ko` | 한국어 | |

### 8.2 実装方針

- DBに入る文言（キュー名・席の選択肢・券面の注意文言）は **JSONB** で言語別に保持し、`i18n()` 関数または クライアントの `t(obj, locale)` で取り出す
- UI固定文言（ボタンラベル等）は `src/lib/i18n.ts` の辞書オブジェクトで持つ。ライブラリは使わない（4言語・数百語なので不要）

```typescript
// src/lib/i18n.ts
export const dict = {
  ja: { chooseService: 'ご用件をお選びください', issue: '整理券を発行する',
        groupsAhead: 'お待ちの組数', estWait: '目安待ち時間', /* ... */ },
  en: { chooseService: 'Please select a service', issue: 'Get a ticket',
        groupsAhead: 'Groups ahead', estWait: 'Estimated wait', /* ... */ },
  zh: { /* ... */ },
  ko: { /* ... */ },
} as const;

export const t = (locale: Locale, key: keyof typeof dict.ja) =>
  dict[locale]?.[key] ?? dict.ja[key];

// DBのJSONB用
export const tj = (obj: Record<string, string>, locale: Locale) =>
  obj?.[locale] ?? obj?.ja ?? obj?.en ?? '';
```

### 8.3 言語の伝播

キオスクで選択された言語は `tickets.locale` に保存され、**券面の印字**と**ステータス画面の初期表示**に引き継がれる。ゲストは画面上で切り替えることもできる。

スタッフ画面と管理画面は日本語のみ（外国人スタッフがいる場合は英語も追加する）。

## 9. アクセシビリティ

| 項目 | 対応 |
|---|---|
| コントラスト | 本文4.5:1以上、大文字3:1以上を全画面で満たす |
| 文字サイズ | キオスクの本文は最小20px、ゲスト画面は最小16px |
| 色だけに依存しない | 長時間待ちの警告は、背景色に加えて `⚠` アイコンも出す |
| スクリーンリーダー | ゲストステータス画面の「あと N組」に `aria-live="polite"` を付ける |
| 動きの抑制 | `prefers-reduced-motion` が有効なら、明滅を「静止した赤背景」に置き換える |
| キーボード操作 | スタッフ画面は Tab で全操作に到達できる。`Space` = 次を呼ぶ、`Enter` = ご案内 のショートカットを用意 |
